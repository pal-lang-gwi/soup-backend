[[auth]]
== Auth

인증 관련 API는 JWT 토큰 기반 인증을 관리합니다.

NOTE: 토큰 재발급 시 기존 Refresh Token을 사용하며, 새로운 Access Token과 Refresh Token이 발급됩니다.

=== 인증 흐름

1. 사용자 로그인 → Access Token & Refresh Token 발급
2. Access Token으로 API 호출 (Authorization: Bearer {token})
3. Access Token 만료 시 Refresh Token으로 재발급
4. 로그아웃 시 토큰 무효화

'''

=== 토큰 재발급

Access Token 만료 시 Refresh Token을 사용하여 새로운 토큰 쌍을 발급받습니다.

* *Endpoint:* `POST /api/auth/refresh`
* *Method:* POST
* *Authentication:* Refresh Token Required

사용자를 로그아웃하고 토큰을 무효화합니다.

* *Endpoint:* `POST /api/auth/logout`
* *Method:* POST
* *Authentication:* Required
