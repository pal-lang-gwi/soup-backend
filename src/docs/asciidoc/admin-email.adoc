== Admin Email

관리자용 이메일 관리 API입니다.

WARNING: 모든 Admin API는 관리자 권한이 필요합니다. 일반 사용자는 403 Forbidden 오류가 발생합니다.

=== 이메일 테스트 전송

뉴스 이메일을 테스트로 전송합니다. 실제 발송 전에 테스트용으로 사용합니다.

* *Endpoint:* `POST /api/admin/email/test`
* *Method:* POST
* *Authentication:* Admin Required
