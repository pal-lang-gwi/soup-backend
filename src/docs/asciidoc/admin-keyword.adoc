== Admin Keyword

관리자용 키워드 관리 API입니다. 키워드를 직접 추가하거나 삭제할 수 있습니다.

WARNING: 모든 Admin API는 관리자 권한이 필요합니다.

시스템에 등록된 모든 키워드를 조회합니다.

* *Endpoint:* `GET /api/admin/keywords`
* *Method:* GET
* *Authentication:* Admin Required

* *Method:* DELETE
* *Authentication:* Admin Required
