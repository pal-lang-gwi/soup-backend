== 📖 Overview

SOUP는 사용자가 관심있는 키워드를 구독하면 해당 키워드와 관련된 뉴스를 이메일로 받아볼 수 있는 서비스입니다.

=== Base URL
[source]
----
https://api.soup.palangwi.com
----

=== Response Format
모든 API 응답은 JSON 형식입니다.

[source,json]
----
{
  "success": true,
  "message": "Success",
  "data": { ... }
}
----

=== HTTP Status Codes
|===
|상태 코드|설명

|200 OK
|요청이 성공적으로 처리됨

|201 Created
|리소스가 성공적으로 생성됨

|204 No Content
|요청은 성공했으나 응답 본문이 없음

|400 Bad Request
|잘못된 요청 (유효성 검증 실패)

|401 Unauthorized
|인증 실패 또는 인증 토큰 누락

|403 Forbidden
|권한이 없음 (관리자 전용 API)

|404 Not Found
|요청한 리소스를 찾을 수 없음

|409 Conflict
|리소스 충돌 (중복된 데이터)

|500 Internal Server Error
|서버 내부 오류
|===
