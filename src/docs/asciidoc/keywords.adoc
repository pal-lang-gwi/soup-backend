[[keywords]]
== Keywords

키워드 관련 API는 사용자가 관심 키워드를 구독하고 관리할 수 있는 기능을 제공합니다.

NOTE: 모든 키워드 API는 인증이 필요합니다. Authorization 헤더에 Bearer 토큰을 포함해야 합니다.

=== 키워드 목록 조회

전체 키워드 목록을 페이지네이션으로 조회합니다.

* *Endpoint:* `GET /api/keywords`
* *Method:* GET
* *Authentication:* Required

TIP: 페이지 크기는 쿼리 파라미터로 조정할 수 있습니다. 기본값은 20개입니다.

=== 키워드 구독

새로운 키워드를 구독합니다. 구독한 키워드는 뉴스 이메일에 포함됩니다.

* *Endpoint:* `POST /api/keywords/subscribe`
* *Method:* POST
* *Authentication:* Required

WARNING: 이미 구독 중인 키워드를 다시 구독할 수 없습니다.

=== 키워드 요청

목록에 없는 새로운 키워드를 관리자에게 요청합니다.

* *Endpoint:* `POST /api/keywords/request`
* *Method:* POST
* *Authentication:* Required

TIP: 요청한 키워드는 관리자의 승인 후 목록에 추가됩니다.
