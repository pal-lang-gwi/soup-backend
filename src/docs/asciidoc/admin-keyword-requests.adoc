WARNING: 모든 Admin API는 관리자 권한이 필요합니다.

사용자들이 요청한 키워드 목록을 조회합니다.

* *Endpoint:* `GET /api/admin/keyword-requests`
* *Method:* GET
* *Authentication:* Admin Required

=== 키워드 승인

사용자가 요청한 키워드를 승인하여 시스템에 추가합니다.

* *Endpoint:* `POST /api/admin/keyword-requests/{requestId}/approve`
* *Method:* POST
* *Authentication:* Admin Required

TIP: 승인 시 키워드가 자동으로 목록에 추가되며, 요청한 사용자에게 알림이 발송됩니다.

=== 키워드 거절

사용자가 요청한 키워드를 거절합니다. 거절 사유를 함께 전달할 수 있습니다.

* *Endpoint:* `POST /api/admin/keyword-requests/{requestId}/reject`
* *Method:* POST
* *Authentication:* Admin Required

NOTE: 거절 사유는 선택사항이지만, 사용자에게 피드백을 제공하기 위해 작성하는 것을 권장합니다.
