[[user]]
== User

사용자 계정 관리 API입니다.

NOTE: 대부분의 사용자 API는 인증이 필요하며, 본인의 정보만 조회/수정할 수 있습니다.

=== 사용자 초기 설정

신규 사용자의 닉네임과 프로필을 설정합니다. (최초 1회)

* *Endpoint:* `POST /api/users/init`
* *Method:* POST
* *Authentication:* Required

TIP: 소셜 로그인 후 최초 1회만 호출됩니다.
