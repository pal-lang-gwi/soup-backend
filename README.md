# 🧠 관심사 기반 정보 요약 서비스

본 서비스는 대규모 언어 모델(LLM, Large Language Model)을 활용하여  
사용자의 관심 키워드에 따라 맞춤형 정보를 탐색하고 요약하여 제공하는 **정보 큐레이션 플랫폼**입니다.

---

## 🎯 주요 기능

### 🔍 관심사 기반 정보 탐색
- 사용자가 등록한 키워드를 기반으로 웹 상의 관련 정보 수집
- Perplexity API를 통한 자연어 요약 처리
- 뉴스, 트렌드, 콘텐츠 등 다양한 정보 소스 연계

### 🧠 AI 요약 및 큐레이션
- 사용자에게 맞춤형 요약본 생성 (일간/주간 요약)

### ✍️ 키워드 관리 및 추천
- 사용자 키워드 등록/수정 기능
- 관리자는 사용자의 요청 키워드를 승인/거절 가능

### 💌 뉴스레터 및 정보 전달
- 요약 정보 메일 발송 (트래킹 기능 포함)
- 메일 오픈 확인을 위한 추적 이미지 삽입 지원
- Firebase 기반 알림 또는 실시간 챗봇 응답 연계 가능

---

## 🛠️ 기술 스택

| 영역       | 사용 기술 |
|------------|-----------|
| LLM        | Perplexity |
| 백엔드     | Spring Boot, PostgreSQL, MongoDB, Redis |
| 프론트엔드 | React, Typescript, TailwindCSS |
| 인프라       | Docker, GitHub Actions |

---

## 📦 프로젝트 구조

```

soup-backend/
├── controller/         # REST API 컨트롤러
├── service/            # 뉴스 요약 및 키워드 처리 로직
├── domain/             # 도메인 모델 (News, Keyword, User 등)
└── repository/         # MongoDB, Redis 기반 저장소

````

---

## 🧩 사용 예시

1. 사용자가 키워드 "인공지능" 등록
2. LLM이 관련 뉴스와 정보를 탐색 및 요약
3. 요약 결과를 평일에 메일로 발송
